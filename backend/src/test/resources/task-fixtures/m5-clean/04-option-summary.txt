주문 화면의 선택 옵션 요약을 검토합니다. OptionSummary는 옵션 목록을 표시하고 SelectionReport는 항목 수가 포함된 요약을 제공합니다.
1단계에서 기존 요약의 입력 사례를 점검하고, 2단계에서 항목 수가 포함된 요약을 완성하고, 3단계에서 여러 종류의 문자가 포함된 옵션을 점검합니다.
NOTES.md에는 서로 다른 매장의 표시 사례가 있습니다. 빈 항목과 중복 항목에 적용할 정책을 각각 정하고 선택 근거를 설명해 주세요.
OptionSummary.format 입력과 출력 예: null → "선택 없음", [] → "선택 없음", ["연필"] → "연필", ["연필", "지우개"] → "연필 / 지우개".
OptionSummary.format 입력과 출력 예: ["ABCD"] → "ABCD", ["ABCDE"] → "ABCD…", ["😀ABC"] → "😀ABC", ["😀ABCDE"] → "😀ABC…".
문자는 유니코드 코드 포인트를 뜻한다. 표시되는 각 항목의 원문 부분은 최대 네 문자이며, 원문의 나머지가 있는 항목에는 …가 표시된다.
SelectionReport.format 입력과 출력 예: null → "선택 0개: 선택 없음", [] → "선택 0개: 선택 없음", ["연필", "😀ABCDE"] → "선택 2개: 연필 / 😀ABC…".
SelectionReport의 숫자는 표시 항목의 수이며, 콜론 뒤의 내용은 같은 입력에 대한 OptionSummary의 결과와 같다. 표시 항목의 순서는 입력 순서와 같다.
목록 안의 null 항목과 공백만 있는 항목, 중복 항목의 표시는 NOTES.md의 각 사례 중 선택한 정책에 따른다. 빈 항목 정책은 두 종류의 빈 항목에 동일하게 적용된다.
